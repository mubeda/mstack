Build a help page for Example Ledger, a small invoicing app, as one HTML file, `help.html`, with its CSS and whatever script it needs. This is a plain HTML project. The page has no animation.

It needs four things:

1. A site navigation with the links Home, Invoices and Help, and one drop-down called Account that holds three links: Profile, Billing and Sign out.
2. A filter for the questions with exactly three options, of which one is always chosen: All topics, Invoices, Payments.
3. These twelve questions, each with a short answer you write (two sentences at most, no invented numbers): How do I create an invoice? How do I send one? Can I change an invoice after sending it? How do I add my logo? Which currencies can I use? How do I record a payment? What happens when a payment is late? Can a customer pay by card? How do I refund a payment? How do I export my invoices? Can I invite my accountant? How do I close my account?
4. A warning that appears when the user has been idle: "Your session ends in one minute", with a button "Stay signed in". Add a link "Show the session warning" at the bottom of the page that opens it, so it can be tried.
