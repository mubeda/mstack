Add a settings screen to this app, as `src/Settings.jsx`, and show it from `src/App.jsx` beside the projects screen.

It needs:
- a profile form with a name, an e-mail address and a switch for e-mail notifications, saved with `saveProfile` from `src/api.js`;
- the list of team members from `fetchMembers` in `src/api.js`, each with a name and an e-mail address;
- a way to remove a member, with `removeMember` from `src/api.js`.

Use what the app already has. Do not install anything.
