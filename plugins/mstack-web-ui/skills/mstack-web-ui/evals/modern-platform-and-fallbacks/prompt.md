Build a plain HTML page `notes.html` (HTML, CSS and inline JS, no build step or external dependencies) for Example Notes:

1. A `<search>` filter bar with an input that shows validation feedback only after interaction when required text is missing.
2. A note composer with a textarea that grows automatically with its content (within sensible min and max heights).
3. A "Shortcuts" help button that opens a small non-modal popover anchored next to the button.
4. A "Clear note" button that opens a confirmation modal dialog supporting light-dismiss on outside click as well as Escape and an explicit Cancel button.

The page must use modern HTML and CSS platform features where available and degrade cleanly with fallbacks in browsers that do not yet support Newly Available features.
